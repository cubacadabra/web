Start with Cuboom

Restore loose letter strokes to pushable cubes and build a tower together. Help us improve its playability, multiplayer behavior, and creator workflow.

Play Cuboom Read the game source ↗

Keep rust, tools, examples, and studio as sibling checkouts. Install stable Rust, then run from their parent directory:

cargo run --manifest-path tools/Cargo.toml --bin cubacadabra -- \
  build-game examples/cuboom --output examples/cuboom/build/package
cargo run --manifest-path studio/Cargo.toml -- --path examples/cuboom

Press Play in Studio. Local creation and preview are free and require no account. Multiplayer shared state needs a reachable backend; the backend README covers local setup.

What works today

Author and preview
Scene hierarchy, properties, grouping, transforms, undo, save/rebuild, and Play/Stop use the same source and runtime as the CLI.
Bring a Roblox project
XML import converts supported scene content. Scripts, unsupported classes, and external assets need review and adaptation. Import limits ↗
Test across hosts
Web, iOS, Android, and Desktop share Rust runtime behavior. Device conformance and performance evidence are still being built.
Know the limits
Trusted game authority, durable progression, complete Morph package wiring, and shared editing remain open work. Roadmap ↗

Share a build or a fix

Open an issue or pull request in the repository that owns the change. Include reproduction steps and the host you tested. The docs repository owns cross-repository contracts.
