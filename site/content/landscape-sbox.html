s&box is the serious engine comparison.

Facepunch is building a modern game-creation platform on Source 2 with an intuitive editor and the latest .NET technology. It is a real technical reference point—not a straw man.

The stack contrast

Rust gives cubacadabra a different center of gravity.

s&box’s public repository describes a Source 2 engine built around .NET, with C# as the creator-facing path and Visual Studio plus the .NET SDK in the source-build prerequisites. Its engine source is MIT-licensed, while certain native binaries remain under an EULA.

cubacadabra’s bet is a Rust runtime that can compile to WebAssembly and native clients from the same core. That is not automatically “better,” but it is a meaningful advantage for a small team trying to keep web, iOS, and Android behavior aligned.
