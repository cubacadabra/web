Landscape / Platform profile

The Mirror is the closest thesis match.

The Mirror pitched an open Roblox and UEFN alternative, reached 1.3k GitHub stars, and then moved from Godot toward a TypeScript V2 with parts of the project planned as open core.

Why it matters

Someone else is already proving the question is interesting.

The Mirror is a useful signal because it takes the open-source alternative idea seriously: the editor and game meet in one place, multiplayer is part of the authoring experience, and the repository is explicit about the transition from Mirror Classic to a TypeScript-based engine.

That pivot is fascinating, and it also shows how hard the problem is. cubacadabra should be clear about what is open today, what is experimental, and what the platform needs to operate safely.
